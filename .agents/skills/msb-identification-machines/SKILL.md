# Identifier les machines MySelfieBooth
À utiliser lors de toute modification des images, des descriptions de prestations, d'une maquette ou des pages machines.

1. Lire `docs/MACHINES_VALIDATION.md` et les pages correspondantes du dépôt ; vérifier les photos / vidéos réelles.
2. Distinguer : Photobooth = borne photo noir/doré, tirages selon formule ; Miroirbooth = grand miroir tactile encadré de doré ; 360 = plateforme et bras rotatif vidéo ; Air360 = grand format spécifique ; Vogue = couloir/studio lumineux effet magazine ; iPad = borne photo numérique compacte.
3. Phonebooth = téléphone enregistrant la voix ; livre d'or vidéo = caméra enregistrant des messages ; ne pas substituer l'un à l'autre.
4. Ne pas utiliser une photo 360 classique comme démonstration de l'Air360. La source `air360-en-action.gif` a été écartée pour cette confusion.
5. Pour les visuels assistés par IA, partir de vrais médias de la machine concernée, préserver géométrie, personnes et identité ; respecter `docs/IMAGE_AI_PROMPTS.md` et le manifeste de provenance.
6. Si une référence physique précise n'est pas vérifiable (dimensions, version, capacités), la déclarer inconnue, sans invention.
