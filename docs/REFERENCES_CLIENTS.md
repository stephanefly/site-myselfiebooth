# Références clients autorisées sur le site

Sélection explicitement confirmée par le responsable de MySelfieBooth pour l'affichage public :

| Entreprise | Logo existant |
| --- | --- |
| TotalEnergies | `public/logos/totalenergies.png` |
| Safran | `public/logos/safran.webp` |
| Sephora | `public/logos/sephora.webp` |

La présence d'un logo dans `public/logos/`, d'une société dans un indice boursier ou d'une mention dans un ancien document **ne suffit pas** à autoriser son affichage comme référence client.

Ne pas ajouter d'autres marques dans `src/data/site.js` sans validation explicite et vérifiable. Les anciennes listes plus larges ne constituent pas une validation publique. Conserver uniquement des réalisations et médias réels, dont la publication est autorisée.
